# Laith & Anwar Invitation

Standalone responsive HTML/CSS/JavaScript recreation inspired by the supplied Canva invitation.

## Event details reproduced from the reference
- Saturday, 26 September 2026
- 15 Rabi' al-Thani 1448 AH
- 7:00 PM–9:00 PM
- Al Sharq Celebrations Hall
- Royal Hall — Irbid

## Files
- `index.html` — invitation structure and content
- `styles.css` — responsive olive/off-white visual system, botanical decoration, opening scene and transitions
- `script.js` — opening interaction, reveal animations, subtle floating leaves and RSVP placeholder interaction

## RSVP
The reference invitation does not expose an external RSVP destination. The recreated RSVP button is therefore intentionally left without a third-party endpoint. It can later be connected to a Google Form/Sheet, WhatsApp, or another RSVP service.
